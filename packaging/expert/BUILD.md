# Build the expert upload ZIP

From the repository root, build the runtime package sequentially and then assemble the expert ZIP:

```sh
pnpm pack:plugin
python3 scripts/package-workbuddy-expert.py
```

Output: `.data/packages/univer-office-expert-0.1.0.zip`. The sibling `expert-package-audit.json` records the archive hash and exact file list. The script uses the runtime packager's audited whitelist; it excludes the development plugin manifest and duplicate runtime Skills.

The expert manifest and local HTTP MCP declaration are generated by the Python script. The author email was supplied for public display. `avatar.png` is the supplied Univer Office logo resized to 512×512. The package README explains manual runtime startup and token entry; neither successful ZIP validation nor inclusion of built files proves automatic installation or official approval.

Reference: https://open.workbuddy.cn/docs/expert
