# Doc

Use the `doc` binding and discover the installed public paragraph, text, table and page methods with `univer_api`. Preserve document structure when replacing text; do not rebuild an imported document just to change a paragraph.

Set requested font, paragraph spacing and actual table borders through public Facades. Editor gridlines do not establish exported borders. Check pagination with a real SDK screenshot, then inspect representative DOCX output in an independent compatible reader. A basic one-page document and table have been verified in Word; headers, footers, complex pagination and embedded content require their own checks.

Use `univer_export` for a new DOCX and `univer_print_pdf` for PDF. Report the checked content and any remaining fidelity gap.
